# Wood Law Offices — demo website

Demo site for Wood Law Offices (Parsons & Lexington, Tennessee).

Pages:
- `index.html` — home: introduction, practice areas, attorney preview, office locations, consultation link
- `attorneys.html` — attorney profiles
- `consultation.html` — how consultations work, common questions, online request form, staff appointment docket (demo passcode: `wood1982`)

Shared files: `styles.css`, `site.js`. Photos go in `images/` (see `images/README.md`).

Items marked "Office to confirm" on the site need details from the firm (consultation fee policy, response time, attorney biographies).

Demo requests are stored in the visitor's browser only. A production version would connect to a booking backend with email/SMS notifications and a secure staff login.
