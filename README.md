# Wood Law Offices — demo website

Demo site for Wood Law Offices (Parsons & Lexington, Tennessee).

- Corporate site: practice areas, firm, both office locations
- Online consultation booking (office, matter, day, time)
- Staff docket to confirm, decline, cancel or complete appointments (demo passcode: `wood1982`)

Demo bookings are stored in the visitor's browser only. A production version would connect to a booking backend and email/SMS notifications.

A product of [LIT America](https://www.litamerica.net).
